# 家校双邀请试验与下一轮入组

数据来自独立设计的合成业务记录，不含真实人员资料。文件为 UTF-8 JSON。

## 资料字典

`study` 中的时间都是从项目第 0 日算起；跟踪窗口从对应的一轮邀请起算。`students` 是学生、家庭和班级的归属；`classes` 是校区、时段、名额和历史原分配。`dispatches` 保留本来分给学生的两种邀请及是否发出，不能用实际到访反推入组。家长邀请以家庭为单位，故同户的两份记录可能是同一邀请或冲突证据；家长结果不要按学生人数重复计算。`followup` 是查证当日看到的回执，没有回执的一行不能证明已经完成观察。`amendments` 从登记日开始可见，校正家庭事实不改变已发送凭证。`next_round` 提供下一轮上限和已承诺名额，已发送旧凭证仍可用于跟踪。任一阶段的多重比较总错误限额以 `look_alpha` 为准，分析设计没有预指定。

## 读取与核对

使用 Python 3.11。
本地虚拟环境可按 `python3 -m pip install -r requirements.txt` 安装锁定的数值工具。有隔离运行环境时可直接使用已安装版本。

用 `python3 -m json.tool data/records.json` 查看原始记录。用 `python3 -m unittest discover -s tests -v` 核对演练资料的格式及关联。仓库目前只提供资料与输入核对，不提供业务分析结果。
